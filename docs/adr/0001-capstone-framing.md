# Solution Framing Canvas

## 1. Problem
Users often need quick and trustworthy financial guidance, but they may not have the time or expertise to read long articles or interpret complex advice. A simple assistant can help them get practical answers in plain language.

## 2. Target User
The primary users are students, young professionals, and anyone looking for basic financial help without needing a human advisor. They want guidance that is easy to understand and immediately useful.

## 3. User Need / Context
Users need help with everyday financial questions such as saving, budgeting, emergency funds, and basic money management. They want answers that are concise, relevant, and easy to act on.

## 4. Proposed Solution
AIRAG-Capstone is a lightweight retrieval-augmented generation system for finance assistance. It uses a knowledge base and an LLM to provide grounded responses to user questions.

## 5. Value Proposition
The solution offers fast, accessible financial support that feels more helpful than a generic chatbot and more practical than reading through long documents. It makes finance guidance easier to obtain for non-experts.

## 6. Key Features
- Natural-language question input
- Retrieval of finance-related information from a curated knowledge source
- Concise, grounded answers generated by an LLM
- Simple interface that can be expanded for budgeting, investing, and expense analysis

## 7. Success Metrics / Assumptions
Success will be measured by answer relevance, clarity, response speed, and user satisfaction. The core assumption is that users value quick and grounded financial help more than fully personalized financial advice.
